# AI Swarm-Match — aplikacja Expo

Szkielet Expo SDK 58 / Expo Router z lokalnym czatem agenta, kolejką evidence on-device, egress firewallem i odbiorem dopasowań przez Supabase Realtime + Expo Push.

```bash
npm install
cp .env.example .env
npm run web
npm run typecheck
```

Bez `.env` aplikacja startuje w trybie DEMO lokalnego. Telefon nigdy nie łączy się bezpośrednio z Abacus.ai.

Pełna specyfikacja: [`docs/02_EXPO_MOBILE_KROK_D.md`](../../docs/02_EXPO_MOBILE_KROK_D.md).
